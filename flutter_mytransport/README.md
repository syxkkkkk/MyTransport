# MyTransport Malaysia — Flutter App

A full Flutter conversion of the MyTransport Malaysia React/TypeScript web app.

---

## Project Structure

```
flutter_mytransport/
├── pubspec.yaml
└── lib/
    ├── main.dart                          # Entry point & named route setup
    ├── theme/
    │   └── app_theme.dart                 # Color palette & ThemeData
    ├── widgets/
    │   └── bottom_nav_bar.dart            # Shared bottom navigation bar
    └── screens/
        ├── welcome_screen.dart            # Splash / landing screen
        ├── home_screen.dart               # Dashboard with shortcuts
        ├── location_selection_screen.dart # Map + location picker
        ├── route_details_screen.dart      # Journey timeline
        ├── chatbot_screen.dart            # AI assistant chat
        ├── trip_summary_screen.dart       # Post-trip summary + rating
        ├── live_train_notifications_screen.dart
        └── ar_navigation_screen.dart      # AR camera overlay
```

## Screen Flow

```
Welcome → Home ──┬──→ Chatbot ──────────→ RouteDetails
                 ├──→ LocationSelection ─→ RouteDetails
                 ├──→ LiveTrainNotifications
                 └──→ ARNavigation ──────→ TripSummary
```

## Setup & Run

### Prerequisites

| Tool | Version |
|------|---------|
| Flutter SDK | ≥ 3.0.0 |
| Dart SDK | ≥ 3.0.0 |
| Android Studio | Hedgehog or later (for Android emulator) |
| Xcode | 15+ (for iOS simulator, macOS only) |

Check your Flutter installation:
```bash
flutter doctor
```

---

### 1. Bootstrap the project (one-time)

Because the android/ios platform folders are generated by Flutter tooling,
run this inside the `flutter_mytransport/` directory first:

```bash
cd flutter_mytransport
flutter create . --project-name mytransport --org com.mytransport
```

This generates the platform directories (`android/`, `ios/`) without
overwriting the `lib/` files or `pubspec.yaml` you already have.

---

### 2. Install dependencies

```bash
flutter pub get
```

---

### 3. Run on an Android emulator

```bash
# List available emulators
flutter emulators

# Launch one (e.g. Pixel 8)
flutter emulators --launch Pixel_8_API_34

# Run the app
flutter run
```

Or just:
```bash
flutter run   # Flutter will prompt you to pick a device
```

---

### 4. Run on an iOS simulator (macOS only)

```bash
open -a Simulator
flutter run
```

---

### 5. Build a release APK (Android)

```bash
flutter build apk --release
# Output: build/app/outputs/flutter-apk/app-release.apk
```

## Color Palette

All colors are defined in `lib/theme/app_theme.dart` as `AppColors` constants,
mirroring the original CSS custom properties exactly:

| Token | Hex |
|-------|-----|
| `primary` | `#4F46E5` |

| `secondary` | `#0EA5E9` |
